## 🔄 Workflow d'onboarding unifié

Les 5 étapes du workflow sont **identiques** pour maritime et aviation :

1. **DÉTECTION AUTOMATIQUE**
   - Maritime : sync VesselFinder + Port Berbera (6h)
   - Aviation : sync plans de vol SCAA + FlightRadar24 (6h)

2. **CALCUL AUTOMATIQUE CO₂**
   - Maritime : formule Admiralty × 3,114 × 50 % × USD 40
   - Aviation : LTO + Cruise × RFI 2.0 × USD 40

3. **INVITATION** — Email initial + pro-forma + kit onboarding

4. **KYC / SIGNATURE** — Formulaire de conformité + signature

5. **ACTIVATION** — Portail self-service + facturations automatiques

## 💰 Recouvrement automatique — Workflow identique

Le module `RECOUVREMENT_AUTOMATIQUE.md` couvre **les 2 volets** :

- Paiement SWIFT reçu (référence `PRO-2026-064XXX` maritime ou `AVI-2026-XXXX` aviation)
- Auto-matching par regex sur référence
- Mise à jour statut pro-forma (PENDING → PARTIAL → PAID)
- Notifications automatiques (Direction, débiteur, cabinet d'avocats)
- Bilans hebdo et mensuel auto-régénérés

Les 5 règles de matching s'appliquent aux 2 types de références.
