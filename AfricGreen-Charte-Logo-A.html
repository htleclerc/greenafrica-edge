1. Identité

Logo A — Écusson Bouclier

Un blason moderne inspiré des armoiries africaines. Le bouclier symbolise la souveraineté et la protection des données carbone. La feuille stylisée intégrée représente la végétation côtière. Les vagues maritimes en base ancrent le projet dans les zones portuaires.

7. Règles d'utilisation

À faire · À ne pas faire

Ces règles garantissent la cohérence et l'intégrité visuelle du Logo A sur toutes les surfaces.

✓ À FAIRE
✅
Fond sombre en priorité

Toujours utiliser le logo sur fond #0A1110 ou fond sombre proche. C'est la version canonique du produit.

✅
Respecter le clearspace

Maintenir une zone libre égale à la hauteur du « A » autour du logo complet.

✅
SVG vectoriel uniquement

Utiliser le fichier SVG source pour tous les usages. PNG uniquement si SVG impossible (email legacy).

✅
Version icône seule sous 80px

En dessous de 80px de largeur totale, utiliser l'icône bouclier seule sans le texte.

✅
Taille minimale : 80px largeur

La version lockup complète (icône + texte) ne doit pas être utilisée sous 80px.

✗ À NE PAS FAIRE
🚫
Ne pas changer les couleurs

Le dégradé Emerald est intouchable. Pas de rouge, pas de violet, pas de couleurs de marque concurrentes.

🚫
Ne pas déformer ou étirer

Le ratio icône/texte et les proportions du bouclier sont figés. Redimensionner proportionnellement uniquement.

🚫
Pas d'ombre portée sur l'icône

La box-shadow est définie dans les tokens. Ne pas ajouter d'effets non standards (glow excessif, stroke externe).

🚫
Pas d'inline hex dans le code

Utiliser exclusivement les CSS variables --ais-primary, --ais-dark.

🚫
Pas sur fond vert ou coloré

L'icône sur fond blanc ou vert clair uniquement si version monochrome Emerald est utilisée.
