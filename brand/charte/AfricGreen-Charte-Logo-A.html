5. Règles

À faire · À ne pas faire

Ces règles garantissent la cohérence visuelle du Logo A sur toutes les surfaces.

✓ À FAIRE
✅
Fond sombre en priorité

Version canonique sur #0A1110. C'est la déclinaison principale.

✅
SVG vectoriel uniquement

Utiliser le SVG source. PNG uniquement si SVG impossible (email legacy).

✅
Icône seule sous 80px

En dessous de 80px de largeur, utiliser l'icône bouclier seule sans texte.

✅
Clearspace = hauteur du "A"

Zone libre autour du logo ≈ 16px à taille standard.

✗ À NE PAS FAIRE
🚫
Ne pas changer les couleurs

Le dégradé Emerald est intouchable. Pas de rouge, violet ou autres marques.

🚫
Ne pas déformer ou étirer

Proportions figées. Redimensionner proportionnellement uniquement.

🚫
Pas d'inline hex dans le code

Utiliser exclusivement les CSS variables --ais-primary.

🚫
Pas sur fond vert ou coloré

L'icône sur fond blanc/vert clair uniquement en version monochrome Emerald.
